# Interactive web design system

Dark editorial surfaces, restrained glass, large product typography, evidence-dense cards, and motion that explains system state.

- Taste Skill v2: audit-first redesign and deliberate hierarchy.
- awesome-design-md: explicit visual constraints and developer-tool precision.
- React Three Fiber: declarative system map.
- ShaderGradient v2: ambient moving field with capped pixel density.
- liquid-glass-js: visual reference only; CSS glass avoids depending on an upstream React/accessibility roadmap.
- liquid-logo: shader reference only; the center orb uses original GLSL displacement and Fresnel edges.

Motion honors reduced-motion preferences; WebGL has a fallback; no remote font, model key, database, analytics service, or paid API is required. Deploy `frontend/` as the Vercel Root Directory.
